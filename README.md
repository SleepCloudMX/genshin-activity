# 活动观测

原神限时活动的支持率、倍率与下注结果分析。

站点是纯静态页面，部署在 GitHub Pages，无构建、无服务器依赖。

## 内容

- 活动索引：按版本与开始日期浏览活动。
- 支持率与赔率：观察支持率与结算倍率的关系。
- 策略评估：固定选边与随机选边的历史回测。
- 上帝视角：理论上界与对应的下注计划。
- 明暗主题与移动端布局。

## 访问

打开 GitHub Pages 首页，选择活动即可。

活动也可以通过 `?event=<id>` 直接进入，例如 `?event=7.1-261012`。

## 本地查看

直接双击根目录的 `index.html`。

## 数据与新增活动

- `data/activities.js`：活动清单。
- `data/<id>.js`：单个活动的数据，注册到 `window.ACTIVITY_DATA_BY_ID`。

新增活动：

1. 创建 `data/<id>.js` 并注册数据；
2. 在 `data/activities.js` 中增加一条索引；
3. 打开 `index.html?event=<id>`。

修改数据后刷新页面即可。

## 技术

- 原生 HTML / CSS / JavaScript，无构建步骤。
- 图表使用本地 ECharts。
- 活动数据按需加载。
